Question 1: What is Terraform?

Terraform is an Infrastructure as Code tool that lets us provision and manage infrastructure using simple configuration files instead of doing everything manually.

Question 2: What is the purpose of Git?

Git is a version control system. It helps us track changes, keep a history of our project, and collaborate easily with other engineers.

Question 3: Why should engineers confirm tool versions?

It's important to check tool versions to make sure everything is installed correctly and compatible with the project. It also saves a lot of time when troubleshooting later.
