Terraform Lab 02 — Knowledge Check

Question 1: Resource Type vs Resource Name

Resource type tells Terraform what kind of resource it's managing.
Resource name is just a unique label for that resource inside the module.

2: What Does filename Control?

The filename argument sets the path and name of the file Terraform will create, while content is what actually goes inside the file.

Question 3: Why Do We Declare a Provider?

A provider is what allows Terraform to talk to a specific platform or service. In this lab, I used the HashiCorp Local provider because I was just creating a local text file.
