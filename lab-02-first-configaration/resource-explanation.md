Terraform Lab 02 — Resource Explanation

What I Created

In this lab, I created my first ever Terraform configuration using the HashiCorp Local provider.

I defined a resource called local_file.academy_note that creates and manages a text file named academy.txt. Inside the file is the text:

"MZ-UCA Cloud Academy - My First Terraform Resource"

It was a simple resource, but it was exciting to see how Terraform can create and manage actual files from code.

What I Learned

I learned how to write a basic Terraform configuration from scratch — how to declare a provider and define a resource properly.

I also got to practice the core workflow commands like terraform fmt to format my code, terraform init to initialize the project, and terraform validate to make sure everything was correct before deploying.

My configuration passed validation, which was a good sign that I was on the right track.
